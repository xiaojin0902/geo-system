## 三、我们比摘星AI 强的地方

1. **可审计**：每个分数、份额、占比都是规则算出来的，客户能复算；摘星AI 未公开口径。
2. **证据等级 A/B/C**：能区分"AI 说了"和"依据是哪个网页"。
3. **实体消歧**：同名公司（河南恒野农牧等）不会被算成你的可见度——这点连海外产品都常出错。
4. **开源可控 + 零依赖**：30 个模块、331 条测试，可私有化、可二次开发、无供应商锁定。
5. **成本**：一次 12 题真实采集约 ¥0.3；摘星AI 按发文量收费 6,980 元起。

## 四、还差的（如果要 100% 对标）

| 缺口 | 说明 | 需要什么 |
| --- | --- | --- |
| 媒体矩阵真实分发 | 目前是渠道抽象 + dry_run，没有头条/知乎/百家号的真实发文 API | 各平台开放平台账号 / 第三方分发服务 |
| 数字人视频渲染 | **明确不做**（已从系统移除） | 需要时交给外部工具：剪映/腾讯智影等，用我们导出的 SRT+分镜 CSV 即可 |
| 批量排期 UI | 多渠道批量投放的日历视图 | 开发 1-2 天 |
| 客户账号体系 | 目前 Basic Auth 单账号 | 多租户改造（用户表 + 权限 + 隔离） |

> 结论（2026-10-26 更新）：**9 项能力全部有对应实现**；其中 1/2/3/4/5/6/7/8/9 均已落地，唯一不在范围内的是「数字人视频渲染」（已明确移除，不走这条线）和「各平台真实发文 API」（需平台账号或分发服务商）。
