## 二、本轮发现并修复的问题

| # | 问题 | 影响 | 修复 |
| --- | --- | --- | --- |
| 1 | `.env.example` 停留在 5 引擎时代，缺 12 组新变量 | 部署时照文档配不全，功能静默降级 | 重写为 11 引擎 + 发布 + 数字人 + 运行四段完整清单 |
| 2 | 分享链接 `days<=0` 被当成「长期」，过期语义失效 | 客户链接永不过期（安全风险） | 改为 `days=0` 长期、负数即过期 |
| 3 | 重复吊销分享链接返回 true | 运维误判 | 加 `AND revoked=0`，二次吊销返回 false |
| 4 | 服务端分享页用到未导入的 `esc` | 品牌名含特殊字符时可能崩 | 服务端补 `escHtml` 本地转义 |
| 5 | 页面自检脚本误报（把内联 JS 当渲染文本） | 假告警干扰判断 | 改为剥离 script/style 后检查可见文本 |

## 三、当前仍不完善的地方（按优先级）

| 优先级 | 缺口 | 影响 | 建议 |
| --- | --- | --- | --- |
| P0 | 单品牌控制台 + 单账号 | 没法一个后台管多个客户 | 多租户改造（2-3 天） |
| P0 | 周报/月报不会自动推送 | 客户看不到变化，续费难 | 定时任务 + 邮件/企微 webhook（0.5 天） |
| P1 | 无白标（logo/域名/配色） | 对外不像你的产品 | 主题包 + CNAME（0.5 天） |
| P1 | 客户渠道凭据只有全局一份 | 每个客户的公众号 key 混用 | 按品牌存凭据（1 天） |
| P1 | 公网服务靠 Cloudflare 临时隧道 | Mac 关机就断、地址会变 | 一台 VPS 或 Render（需绑卡） |
| P2 | 无客户用量与套餐限制 | 成本不可控 | 按月配额与用量统计（1-2 天） |
| P2 | 无审计日志/角色 | 客户问责时无据可查 | 操作日志表 + 只读角色（1 天） |
| P3 | 数字人渲染 | 只出脚本，不出视频 | 接服务商（需账号）或继续用可拍摄包 |

## 五、结论

- **系统本身是健康的**：测试、页面、命令、闭环、分享链路全部通过。
- **不完善的地方集中在「服务化」而不是「技术缺陷」**：多客户、自动周报、白标、凭据隔离、稳定托管。
- 下一步建议：先做 **多客户隔离 + 周报推送**，再拿 1 个真实客户跑 30 天，用数据验证续费逻辑。
